# 🎬 Video Editor Pro

A modern web-based video editor built using **Next.js**, **React**, **Tailwind CSS**, and **Redux Toolkit**. This project simulates a fully functional video editing experience with drag-and-drop uploads, audio and subtitle editing, overlay management, and export simulation.

---

## 🚀 Features

### 1. 📤 Video Upload Section
- Drag-and-drop upload interface
- Simulated progress bar
- Thumbnail/preview display of uploaded video

### 2. 🎚️ Timeline & Preview
- Responsive video preview using the `<video>` tag
- Mock timeline UI for arranging video/audio segments
- Real-time updates to preview

### 3. 🔊 Audio Management
- Audio waveform display (static/mock)
- Background music uploader
- Time control for audio segments
- Mute/rearrange audio blocks

### 4. 💬 Subtitles & Text Overlays
- Subtitle input editor
- Control subtitle font, position, size, color
- Support for multiple subtitle blocks
- Live overlay on the video

### 5. 🖼️ Image Overlays
- Upload image and overlay it on the video
- Resizable and draggable image component
- Style options like opacity, borders, and animation (mocked)

### 6. 📦 Render & Export
- Mock "Render" button with loading indicator
- Simulated export/download functionality
- User-friendly feedback after "render"
